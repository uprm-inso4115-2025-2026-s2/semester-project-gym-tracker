Onboarding Flow, Home Screen, Workout Session, Progress Dashboard, and Settings Screen.

with no installation required.

++++
<pre class="mermaid">
stateDiagram-v2
    [*] --> Idle
    Idle      --> Active    : Begin
    Active    --> RestTimer : Log set
    RestTimer --> Active    : Timer ends
    Active    --> Paused    : Pause
    Paused    --> Active    : Resume
    Active    --> Completed : Last set done
    Completed --> Saved     : Save
    Paused    --> Abandoned : Discard
    Saved     --> [*]       : Return home
    Abandoned --> [*]       : Return home

    state Idle      : Plan loaded, not yet started
    state Active    : User logging sets and reps
    state RestTimer : Countdown between sets
    state Paused    : Session on hold
    state Completed : All sets done, summary shown
    state Saved     : Data persisted to backend
    state Abandoned : Session discarded, no data saved

== State Descriptions

=== Onboarding Flow

[cols="1,3", options="header"]
|===
| State | Description
| Welcome | Introductory screen shown on first launch.
| Goal selection | User picks a primary fitness goal (weight loss, muscle gain, or endurance).
| Fitness level | User selects their experience level (beginner, intermediate, advanced).
| Equipment | User specifies available equipment and preferred workout days per week.
|===

=== Home Screen

[cols="1,3", options="header"]
|===
| State | Description
| Loading | Skeleton screen shown while fetching today's plan and metrics.
| Populated | Full home screen with daily summary card, streak counter, and quick-start button.
| Empty state | Shown to new users with no logged data; prompts first workout.
| Error | API request failed; displays a human-readable message and a retry button.
|===

=== Workout Session

[cols="1,3", options="header"]
|===
| State | Description
| Idle | Workout plan is loaded and ready; session has not started.
| Active | User is actively logging sets and reps.
| Rest timer | Countdown displayed between sets; auto-advances back to Active.
| Paused | Session is on hold; user can resume or discard.
| Completed | All sets finished; summary screen displayed.
| Saved | Session data persisted to the backend; user returned to Home.
| Abandoned | Session discarded without saving; user returned to Home.
|===

=== Progress Dashboard

[cols="1,3", options="header"]
|===
| State | Description
| Loading | Skeleton loaders shown while fetching historical data.
| Populated | Charts, streak counter, and personal records displayed.
| Empty state | No workout history exists yet; onboarding tip shown.
| Error | Data fetch failed; retry button displayed.
| Expanded | Drill-down view for a specific exercise's historical performance.
|===

=== Settings Screen

[cols="1,3", options="header"]
|===
| State | Description
| Default | Read-only view of current preferences.
| Editing | User is actively modifying settings (notifications, units, goals).
| Saving | Changes are being persisted to the backend.
| Saved | Confirmation banner shown; screen auto-resets to Default after 2 seconds.
|===
