=== *2.2 Requirements*

==== *2.2.1 User Stories, Epics, Features*

===== *Epic 1: Workout and Run Logging with Session Details*
As a busy #gym goer#, I want to log gym sessions and runs with essential details so that I can remember what I did and build a consistent routine over time.

Features::
* Log gym sessions, runs, and basic cardio
* Record session duration and estimated calories burned
* Record exercise types performed
* Optional notes per session
* Edit past sessions to correct mistakes
* Reuse a recent session as a starting point for fast logging

User stories::
* As #a busy beginner (e.g. Alejandro)#, I want to log a gym session with duration and a short list of exercise types so that I can record my workout quickly and still remember what I did.
* As #a gym goer who also runs (e.g. Derek)#, I want to log a run with time and distance so that I can track cardio progress alongside my gym routine.
* As #a busy gym goer (e.g. Alejandro)#, I want to copy a recent workout and adjust it slightly so that I do not have to retype the same routine every time.
* As #someone who wants to track specific metrics (e.g. Derek)#, I want to attach an optional note to a session (for example effort level or injury warnings) so that I can understand context when comparing sessions later.
* As #a gym goer prone to logging errors (e.g. Ana)#, I want to edit a past session entry so that my weekly summary reflects what actually happened if I logged something incorrectly.
* As #someone looking to build long-term habits(e.g. Ana)#, I want to record an optional “how it felt” note after a session so that I can connect progress with how sustainable the routine feels.

===== *Epic 2: Consistency Tracking and Streaks*
As someone trying to build a habit, I want the system to track consistency and streaks so that I stay motivated to keep showing up over time.

Features::
* Track days attended versus missed
* Maintain activity streaks based on regular logging
* Visualize consistency patterns over time
* #Preserve visible progress even after a streak break#
* #Track recovery progress after a streak break#

User stories::
* As #a gym goer who is easily discouraged (e.g. Alejandro)#, I want to see my current streak of active days so that I feel motivated to keep the routine going.
* As #a gym goer looking to build long-term habits (e.g. Ana)#, I want to see how many days I was active versus missed in the current week so that I can notice gaps early and adjust.
* As #a gym goer and a runner (e.g. Derek)#, I want my streak to count both runs and gym sessions so that the tracking matches my real routine.
* #As a gym goer who struggles with consistency (e.g. Alejandro), I want weekly progress to remain visible even if my streak breaks so that one missed day does not erase my sense of progress or make me stop tracking.#
* #As a gym goer who is restarting after a missed day (e.g. Ana), I want the app to show recovery progress after a streak break so that returning to my routine feels measurable and encouraging instead of starting from zero.#

===== *Epic 3: Goals and End-of-Week Feedback*
As a #gym goer# who needs accountability, I want daily and weekly goals with an end-of-week summary so that I can see whether I met my targets and adjust realistically.

Features::
* Daily and weekly goal setting
* End-of-week summary table
* Progress comparison against goals
* Session-to-session comparisons over time
* Weekly reflection note (optional)

User stories::
* As #a gym goer that wants to follow a specific routine (e.g. Ana)#, I want to set a weekly goal for number of active days so that I have a clear target to aim for.
* As #a gym goer who wants an easy-to-understand tracker (e.g. Alejandro)#, I want an end-of-week summary table showing what I completed versus my goal so that I can feel rewarded and know what to improve next week.
* As #someone who likes to make data-driven decisions (e.g. Derek)#, I want to see how far I am from my weekly goal during the week so that I can decide when to fit in a session.
* As #a gym goer who wants readily available data (e.g. Derek)#, I want to compare this week’s sessions to last week’s sessions so that I can notice improvement or decline without digging through individual logs.
* As #a gym goer that prioritizes efficiency and motivation (e.g. Alejandro)#, I want a simple “goal met / not met” result with a short, supportive explanation so that feedback stays clear and not overwhelming.
* As #a gym goer creating better goals for themselves (e.g. Ana)#, I want to optionally add a quick weekly note about what worked or what got in the way so that I can improve my habits over time.

===== *Epic 4: Reminders and Supportive Encouragement*
As a habit-building #gym goer#, I want reminders and motivational feedback so that I remember to log and stay consistent without feeling pressured.

Features::
* Reminder notifications to encourage consistency
* Supportive tone that avoids judgment
* Basic reminder preferences (enable/disable and frequency)
* Weekly encouragement message based on activity summary
* Temporary mute or quiet mode

User stories::
* As #a gym goer who is easily disengaged by aggressive notifications (e.g. Ana)#, I want to enable reminders on days I usually work out so that I get a helpful nudge when I forget.
* As #a gym goer who is easily frustrated (e.g. Alejandro)#, I want reminder messages to feel supportive rather than judgmental so that notifications encourage me instead of discouraging me.
* As #a gym goer looking to simplify their tracking (e.g. Derek)#, I want to temporarily mute reminders when I am busy so that I do not disengage from the app due to spam.
* As #a gym goer who wants to better their habit tracking (e.g. Ana)#, I want to receive a weekly encouragement message based on my summary so that I stay motivated for the next week.
* As #a gym goer that has a strict schedule (e.g. Alejandro)#, I want reminders to focus on restarting after missed days so that a busy week does not make me give up.

===== *Epic 5: User Accounts and Personal History*
As a regular #gym goer#, I want my activity history stored in an account so that I can review my progress over time and get consistent summaries.

Features::
* User account management
* Personal workout and run history storage
* Individual progress data accessible for summaries and comparisons
* Export or share a simple weekly summary (optional, later extension)

User stories::
* As #a beginner gym goer (e.g. Alejandro)#, I want to create an account so that my workout history is saved and I do not lose progress.
* As #someone looking for a unified tracker (e.g. Derek)#, I want to view my full workout and run history so that I can look back and plan future sessions.
* As #a gym goer interested in creating habits (e.g. Ana)#, I want my weekly summaries to use my saved history so that progress feedback stays consistent over time.
* As #a gym goer and a runner (e.g. Derek)#, I want to filter my history by activity type (run vs gym) so that reviewing progress is fast and meaningful.
