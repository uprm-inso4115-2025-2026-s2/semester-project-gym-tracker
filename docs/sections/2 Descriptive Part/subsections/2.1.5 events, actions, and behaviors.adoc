==== 2.1.5 Events, Actions, and Behaviors

===== Domain Events

[.underline]#The events listed here use the exact names and definitions established in Section 2.1.2. Each entry below is a reference to the corresponding concept in the terminology, not a separate definition. The purpose of this subsection is to show how these events appear in the context of the behaviors described below, not to restate or redefine them.#

*Workout Session has just been performed*
[.underline]#An event in which a Workout Session has occurred at a specific time on a specific Calendar Day. (Defined in Section 2.1.2.)#

*Workout Session has just been skipped*
[.underline]#An event in which an expected opportunity for workout activity has passed without a Workout Session occurring. (Defined in Section 2.1.2.)#

*Goal period has just ended*
[.underline]#An event in which the Time Frame associated with a Goal has completed. (Defined in Section 2.1.2.)#

*Streak has just been extended*
[.underline]#An event in which a Workout Session has occurred on the Calendar Day immediately following an Attendance Day, preserving consecutiveness. (Defined in Section 2.1.2.)#

*Streak has just been broken*
[.underline]#An event in which a Missed Day has occurred after one or more Attendance Days, ending consecutiveness. (Defined in Section 2.1.2.)#

===== Actions

*Perform workout*  
A person engages in physical activity such as exercising, running, or lifting.

*Record workout*  
A person logs details of a completed workout session.

*Set activity goal*  
A person defines a target amount of activity for a future time period.

*Review progress*  
A person inspects their past activity and current consistency.

===== Behaviors

*Maintaining a workout routine*
A repeated pattern of performing workouts across days or weeks.

*Building consistency*
A gradual increase in regularity of attendance over time.

*Tracking progress over time*
A repeated cycle of performing workouts, recording them, and reviewing outcomes.

===== [.underline]#State Machine Diagram: Streak Lifecycle#

[.underline]#The following state machine diagram captures the behavioral lifecycle of a GymGoer's Streak — the primary consistency-tracking concept identified in Section 2.1.2. The diagram models how the system transitions between streak states in response to the domain events described above. It enhances this section by making explicit the conditions under which a Streak is created, extended, placed in a grace period, or broken, supplementing the textual event descriptions with a precise behavioral specification.#

[plantuml, streak-state-machine, svg]
....
@startuml
skinparam state {
  BackgroundColor #1e3a5f
  BorderColor #4a9eca
  FontColor white
  ArrowColor #4a9eca
}
skinparam backgroundColor #0d2137

[*] --> NO_STREAK : GymGoer has no\nworkout history

state NO_STREAK {
  NO_STREAK : No consecutive attendance days recorded.
}

state ACTIVE {
  ACTIVE : currentStreak ≥ 1
  ACTIVE : Most recent qualifying workout\nwas today or yesterday.
}

state GRACE {
  GRACE : currentStreak ≥ 1
  GRACE : Most recent qualifying workout\nwas 2 calendar days ago.
  GRACE : Grace period active — streak\ncan still be recovered.
}

state BROKEN {
  BROKEN : currentStreak = 0
  BROKEN : Most recent qualifying workout\nmore than 2 days ago.
}

NO_STREAK --> ACTIVE : Workout Session recorded /\nfirst qualifying attendance day
ACTIVE --> ACTIVE : Workout Session recorded\non next Calendar Day /\nstreak incremented
ACTIVE --> GRACE : Calendar Day passes\nwith no Workout Session /\ngrace period begins
GRACE --> ACTIVE : Workout Session recorded\nduring grace window /\nstreak continues
GRACE --> BROKEN : Second Calendar Day passes\nwith no Workout Session /\ngrace period expired
ACTIVE --> BROKEN : Two or more Calendar Days pass\nwith no Workout Session
BROKEN --> NO_STREAK : [streak = 0 and\nno prior streak exists]
BROKEN --> ACTIVE : New Workout Session recorded /\nnew streak begins from 1

@enduml
....

[.underline]#*State definitions*#

[cols="1,3", options="header"]
|===
|[.underline]#State# |[.underline]#Condition#

|[.underline]#NO_STREAK#
|[.underline]#The GymGoer has no recorded workout history, or had a broken streak that was reset to zero with no active history prior.#

|[.underline]#ACTIVE#
|[.underline]#The GymGoer has at least one qualifying consecutive Attendance Day. The most recent qualifying Workout Session occurred today or on the immediately preceding Calendar Day.#

|[.underline]#GRACE#
|[.underline]#The current streak is still held but the most recent qualifying workout occurred two Calendar Days ago. The system has not yet invalidated the streak because the grace window allows a late session to recover it.#

|[.underline]#BROKEN#
|[.underline]#The grace period has expired. The current streak resets to zero. Any new Workout Session begins a fresh streak from one.#
|===
